# IssueFoyer

IssueFoyer is a simple, customizable way for people to report problems to an open-source project without needing a GitHub account. Reports become GitHub issues, so maintainers can keep working in the tracker they already use.

The project is designed for a static website hosted on GitHub Pages or a similar service, with a small serverless endpoint to create issues securely. It does not keep a separate report database.

Apertrust is the first intended deployment. IssueFoyer is being built for other projects to use too.

## Status

IssueFoyer is at the design stage. See the [vision and technical design](docs/vision-and-technical-design.md) for the proposed scope and architecture.
